# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on
[this repository](https://github.com/anicke/little-helper/security/advisories/new).
Do not open a public issue for them.

Reports are welcome for `lh` and `lh-tui`, for the release workflow, and for anything that
could make a released binary differ from this repository's source.

## Supported versions

Only the latest release receives fixes.

## Verifying a release

Every release archive has a build-provenance attestation and is listed in `SHA256SUMS`.
See [Verifying a download](README.md#verifying-a-download).
